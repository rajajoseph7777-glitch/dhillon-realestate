# Dhillon Real Estate & Builders

3D website with a Three.js night-city hero, an interactive 3D villa tour (day/night), filterable projects, an EMI calculator and WhatsApp lead capture.

Plain static site (`index.html`, `style.css`, `main.js`). No build step is needed.

Business details (phone, WhatsApp, email, address) and the project list are set in `CONFIG` and `PROJECTS` at the top of `main.js`. The current values are placeholders. Replace them before launch.
